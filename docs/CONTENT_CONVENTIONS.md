# Content Conventions

## Folders
- `library/` for work pages (metadata + core content)
- `authors/` for author profiles
- `docs/` for governance and editorial documentation

## Required front matter for works
- `layout: page`
- `title:`
- `author:`
- `year_first_published:`
- `original_language:`
- `source_url:`
- `tags:`

## Editorial standards
- Include explicit primary-source reference in every work page.
- Separate original work text from editorial notes.
- Cite edition and source URL.
- Prefer simple Markdown over custom HTML.

## Portuguese (pt-BR)
Padrao editorial: metadados obrigatorios, fonte primaria explicita e separacao clara entre texto original e nota editorial.
